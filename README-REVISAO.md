# Prévia de redesign — Diretório de Ramais

Esta pasta é uma cópia independente para revisão. Os arquivos originais enviados e o site publicado não foram alterados.

## Como visualizar
1. Extraia o ZIP inteiro para uma pasta.
2. Abra `index.html` no navegador.
3. Use a navegação para alternar entre SADS, Habitação e Geral.

## O que mudou
- Identidade visual premium com paleta verde-petróleo, fundo claro e detalhes discretos.
- Cabeçalho e navegação mais consistentes.
- Busca e filtros com maior legibilidade.
- Layout móvel com cartões por contato, incluindo rótulos de cada campo.
- Metadados de descrição e pequeno identificador visual no título da página.

## O que foi preservado
- Os dados de contatos nas três páginas.
- Os nomes dos arquivos e links de navegação existentes.
- `script.js` original, incluindo busca sem distinção de acentos, filtros de piso/departamento, contagem e estado vazio.
- Os arquivos de logotipo e favicon originais.

## Antes de publicar
Revise visualmente os dados e teste a busca/filtros no navegador. Esta prévia não foi publicada nem enviada ao GitHub.
