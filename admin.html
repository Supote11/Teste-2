Administração de ramais

Gerencie os ramais das listas SADS e Habitação. A lista Geral permanece no site público, sem cadastro ou edição por este painel.

Acesso administrativo

Entre com as credenciais de admin.json e informe um token do GitHub com acesso de gravação ao repositório de teste. O token será mantido apenas na memória desta página.

O token não será salvo no arquivo nem no navegador. Cole-o somente nesta página e não compartilhe com ninguém.

Gerenciar ramais

As alterações de SADS e Habitação são enviadas diretamente ao arquivo ramais.json no repositório de teste. A lista Geral não é editável neste painel.
