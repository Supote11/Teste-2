# Painel administrativo — Teste-2

## Publicação
1. Faça backup do repositório `Supote11/Teste-2` antes de substituir arquivos.
2. Envie os arquivos desta pasta para a raiz do repositório de teste, mantendo os nomes.
3. Confirme que `index.html`, `habt.html`, `geral.html`, `style.css`, `data-loader.js`, `admin.html`, `admin.js`, `admin.json` e `ramais.json` estão na raiz.
4. GitHub Pages: Settings → Pages → branch `main`, pasta `/(root)`.
5. Abra `https://supote11.github.io/Teste-2/admin.html`.
6. Entre com as credenciais de `admin.json` e cole o token fine-grained do GitHub com acesso somente ao repositório `Teste-2` e `Contents: Read and write`.
7. Faça alterações e clique em **Salvar no GitHub** para atualizar `ramais.json` diretamente.

## Formulários separados
- SADS e Habitação usam formulário de ramal: Responsável, Ramal, Departamento e Piso.
- Geral usa formulário próprio de local: Local, Endereço, Telefone e Responsável.
- Os três tipos são ordenados alfabeticamente por Responsável ou Local, conforme a lista.

## Segurança
`admin.json` em um repositório público é visível para qualquer pessoa e a senha é apenas uma barreira visual. O token é digitado no painel e mantido somente na memória da página; não o grave em arquivos públicos nem o compartilhe. O token deve ter acesso restrito ao repositório de teste.
