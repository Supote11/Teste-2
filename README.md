# Diretório de ramais — ramais

Versão de teste com painel administrativo que pode gravar diretamente em `ramais.json` pelo GitHub Contents API. Consulte `README-ADMIN.md` antes de publicar.


Observação: o painel administrativo permite adicionar, editar e excluir ramais apenas nas áreas SADS e Habitação. A seção Geral permanece no JSON e no site público, sem edição pelo painel.


## Impressão
As páginas SADS, Habitação e Geral possuem o botão “Imprimir lista”. A impressão gera uma versão monocromática compacta, em colunas, usando os resultados visíveis após pesquisa e filtros. Para imprimir todos os registros, limpe a pesquisa e selecione todos os filtros.
